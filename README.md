# Домашнее задание 7

На абстрактном дереве с отношением родитель - потомки реализованы итеративные обходы:

- `bfs` — поиск в ширину, по уровням
- `dfsInorder` — первый ребёнок, узел, остальные дети
- `dfsPreorder` — узел, затем дети
- `dfsPostorder` — дети, затем узел

Рекурсия не используется. Все обходы работают за O(n), где n — число узлов, и используют O(n) дополнительной памяти в худшем случае.

Установка:

```bash
bun install
```

Запуск примера:

```bash
bun run index.ts
```

Тесты:

```bash
bun test
```
